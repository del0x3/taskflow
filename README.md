# TaskFlow — мои daily-задачи

Личный трекер задач на GitHub Issues с автоматизацией. Задачи завожу через Claude (пишу в чат) или сам через форму с телефона; смотрю плотный дашборд.

## 📋 Главное — Доска задач

Закреплённый issue **[📋 Доска задач](../../issues/2)** — плотная таблица всех открытых задач (приоритет, статус, срок, проект, категория), обновляется автоматически. Отметки: 🔥 дедлайн <2ч, ⚠️ просрочено, 🐌 залежалось, секция «✅ Закрыто сегодня». Зеркало — [`DASHBOARD.md`](DASHBOARD.md).

Канбан: **[TaskFlow — Daily](https://github.com/users/del0x3/projects/2)** (Todo / In Progress / Done — перетаскивается с телефона).

## Добавить задачу

- **Через Claude:** «добавь задачу X, приоритет высокий, работа, дедлайн завтра 15:00».
- **Сам с телефона:** Issues → New issue → форма **«Новая задача»** (приоритет/категория/дедлайн) — метки, milestone и исполнитель проставятся сами.

## Типы задач

- **На день** — метка `Сегодня`, без времени. Висит, пока не закроешь.
- **На срок** — `Дедлайн: ГГГГ-ММ-ДД ЧЧ:ММ` в теле. Пуш-напоминания **за 20 мин** и **в момент** (с догоном до −90 мин, если cron задержался).

## Метки

**Статус:** `Сегодня` · `В работе` · `Заблокировано` · `Ожидание` · `Бэклог`
**Приоритет:** `Критично` · `Высокий` · `Средний` · `Низкий`
**Категория:** `Работа` · `Личное` · `Учёба` · `Здоровье` · `Быт`
**Тип:** `Баг` · `Фича` · `Встреча` · `Идея`
**Авто:** `Просрочено` · `Залежалось` (>3 дней) · служебные

## Поля доски

`Приоритет` · `Срок` · `Дедлайн ⏰` · `Начать` · `Где` (@дом/@комп/@телефон/@город) · `Оценка (ч)`

## Автоматизация (GitHub Actions)

| Workflow | Когда | Что делает |
|----------|-------|-----------|
| Ежедневно | 08:00 | milestone дня, всплытие запланированных, роллновер `Сегодня`, повторяющиеся (`recurring.json`, без дублей), дайджест, `Просрочено`/`Залежалось`, вс-ревью, пирамида дайджестов, дашборд |
| Напоминания | каждые 5 мин | эфемерные пуш-комменты (за 20 мин / в момент / догон −90 мин), само-удаление через ~5 мин |
| Доска | issue-события + каждые 30 мин | пересборка дашборда |
| Приёмка | новый issue | разбор формы → метки/milestone/исполнитель/дедлайн |
| Канарейка | 09:00 | пуш, если ежедневный прогон упал/не запускался |
| Вечерний итог | 21:00 | пуш: сколько задач осталось на сегодня |
| Тесты | push скриптов | `bash -n` + тесты дат сворачивания |

**Дайджесты-пирамида** в `digests/`: день → неделя → месяц → квартал → год (младшие сворачиваются в старшие).

## Ограничения

- Колонки доски (Todo/In Progress/Done), вид Table, доп. виды, поле Iteration — настраиваются только в UI Projects.
- В автономных прогонах статус берётся из **меток** (`GITHUB_TOKEN` не читает user-проект); реальная колонка доски — только при ручной пересборке. Полная синхронизация потребовала бы PAT.
- Всё работает на стандартном `GITHUB_TOKEN`, без секретов.

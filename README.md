# TaskFlow — мои daily-задачи

Личный трекер задач на GitHub Issues. Задачи завожу через Claude (пишу в чат — он создаёт), смотрю и перетаскиваю с телефона на доске.

## Доска
[TaskFlow — Daily](https://github.com/users/del0x3/projects/2): **Todo** (на сегодня) → **In Progress** → **Done**.

## Метки

**Статус:** `today` · `doing` · `blocked` · `waiting`
**Приоритет:** `p1-critical` · `p2-high` · `p3-medium` · `p4-low`
**Категория:** `work` · `personal` · `study` · `health` · `errand`
**Тип:** `bug` · `feature` · `meeting` · `idea`

## Ритм
- Каждый день — milestone с датой (напр. `2026-06-06`), видно прогресс «N из M».
- Невыполненное остаётся в Todo и переносится на следующий день.
- Задачи пишем на русском.

# TaskFlow — мои daily-задачи

Личный трекер задач на GitHub Issues. Задачи завожу через Claude (пишу в чат — он создаёт и оформляет), смотрю с телефона.

## 📋 Главное — Доска задач

Плотная таблица всех открытых задач (приоритет, статус, срок, проект, категория) живёт в закреплённом issue **[📋 Доска задач](../../issues/2)** и обновляется автоматически при любом изменении.
Файл-зеркало: [`DASHBOARD.md`](DASHBOARD.md).

Канбан GitHub Projects: **[TaskFlow — Daily](https://github.com/users/del0x3/projects/2)** (колонки Todo / In Progress / Done — перетаскивается с телефона).

## Типы задач

- **На день** — без точного времени, просто метка `Сегодня`. Висит, пока не закроешь.
- **На срок** — дедлайн дата+время (строка `Дедлайн: ГГГГ-ММ-ДД ЧЧ:ММ` в теле). Приходят пуш-напоминания **за 15 мин** и **в момент** дедлайна.

## Метки

**Статус:** `Сегодня` · `В работе` · `Заблокировано` · `Ожидание` · `Бэклог`
**Приоритет:** `Критично` · `Высокий` · `Средний` · `Низкий`
**Категория:** `Работа` · `Личное` · `Учёба` · `Здоровье` · `Быт`
**Тип:** `Баг` · `Фича` · `Встреча` · `Идея`
**Служебные:** `Просрочено`, `Доска`, `Уведомление-до`, `Уведомление-в-момент`

## Поля доски

`Приоритет` · `Срок` · `Дедлайн ⏰` (точное время) · `Начать` · `Где` (@дом/@комп/@телефон/@город) · `Оценка (ч)`

## Автоматизация (GitHub Actions)

- **Ежедневно (08:00, UTC+3):** создаётся milestone дня, незакрытые `Сегодня` переносятся на сегодня, повторяющиеся задачи из [`recurring.json`](recurring.json), дневной дайджест, метка `Просрочено` для протухших дедлайнов, по воскресеньям — ревью недели.
- **Напоминания (каждые 5 мин):** пуш-коммент с упоминанием перед дедлайном и в момент; через ~5 мин коммент сам удаляется, чтобы не копился мусор.
- **Дашборд:** пересобирается при каждом изменении задач.
- **Дайджесты-пирамида** в `digests/`: день → неделя → месяц → квартал → год, младшие сворачиваются в старшие.

## Как пользоваться

- **Через Claude:** «добавь задачу X, приоритет высокий, работа, дедлайн завтра 15:00» — заведёт со всеми метками, полями, milestone и назначит на тебя.
- **Сам с телефона:** доска/дашборд в браузере или приложении GitHub.

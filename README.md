# TaskFlow

Личный трекер daily-задач на GitHub Issues с полной автоматизацией, аналитикой и трекингом привычек. Заводишь задачи через Claude или с телефона — система сама напоминает, считает, рисует графики и палит твою прокрастинацию.

## 🚀 Быстрый старт

- **📋 [Доска задач](../../issues/2)** — закреплённый дашборд: секции «Сегодня» и «Запланировано», привычки, что закрыто, что горит 🔥 и просрочено ⚠️.
- **📊 [Аналитика и диаграммы](https://del0x3.github.io/taskflow/)** — сайт с графиками: прогресс/регресс, время по категориям, стрики, причины просрочек.
- **🗂 [Канбан Projects](https://github.com/users/del0x3/projects/2)** — Todo / In Progress / Done, перетаскивается с телефона.

## Добавить задачу

- **Через Claude:** «добавь задачу X, приоритет высокий, работа, дедлайн завтра 15:00».
- **С телефона:** Issues → New issue → форма «Новая задача».

## Типы задач

- **На день** — метка `Сегодня`, без времени.
- **На срок** — `Дедлайн: ГГГГ-ММ-ДД ЧЧ:ММ` в теле. Пуш за 20 мин и в момент (с догоном до −90 мин).
- **Привычки** — `habits.json`; каждое утро авто-создаётся issue, закрыл = сделал, копится стрик 🔥.

## Трекинг времени

Повесил `В работе` → засекается старт. Закрыл → автоматически считается затраченное время. Всё идёт в аналитику (среднее на задачу, время по категориям).

## Метки

**Статус:** `Сегодня` · `В работе` · `Заблокировано` · `Ожидание` · `Бэклог`
**Приоритет:** `Критично` · `Высокий` · `Средний` · `Низкий`
**Категория:** `Работа` · `Личное` · `Учёба` · `Здоровье` · `Быт`
**Тип:** `Баг` · `Фича` · `Встреча` · `Идея` · `Привычка`
**Авто:** `Просрочено` · `Залежалось` · служебные

## Поля доски

`Приоритет` · `Срок` · `Дедлайн ⏰` · `Начать` · `Где` · `Оценка (ч)`

## Автоматизация (GitHub Actions)

| Workflow | Когда | Что делает |
|----------|-------|-----------|
| Ежедневно | 08:00 | milestone, всплытие запланированных, роллновер, привычки, повторяющиеся, дайджест, `Просрочено`/`Залежалось`, вс-ревью, пирамида дайджестов, дашборд |
| Напоминания | каждые 5 мин | эфемерные пуши, само-удаление |
| Доска | issue-события + 30 мин | пересборка дашборда |
| Статистика | 30 мин | `docs/data.json` для сайта |
| Приёмка | новый issue | разбор формы |
| Трекинг времени | метки/закрытие | старт по `В работе`, расчёт затраченного |
| Канарейка | 09:00 | пуш, если автоматика упала |
| Вечерний итог | 21:00 | сколько осталось на сегодня |
| Тесты | push | `bash -n` + тесты дат |

## Просрочки с причинами

При просрочке бот спрашивает «почему?». Ответ классифицируется: **объективная** (был занят важным) или **субъективная** (😴 лень/прокрастинация). Разбивка — на сайте аналитики.

## Безопасность

Репозиторий публичный (чтобы работал Pages), **но менять данные может только владелец** (`del0x3`): write-доступ закрыт, а issue/комменты от посторонних система игнорирует — учитывает только `del0x3` и `github-actions[bot]`. Всё работает на `GITHUB_TOKEN`, без секретов.

## Ограничения

Колонки доски, Table-вид, поле Iteration — настраиваются в UI Projects. Статус доски в автономных прогонах берётся из метки (`GITHUB_TOKEN` не читает user-проект).

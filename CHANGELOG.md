# Changelog

## v1.0.0 — 2026-06-06

Первый релиз TaskFlow — личного трекера daily-задач на GitHub Issues.

### Возможности
- **Задачи** на день и на срок, метки (статус/приоритет/категория/тип) и поля доски — всё на русском.
- **Доска задач** — закреплённый авто-дашборд (плотная таблица, 🔥/⚠️/🐌, «закрыто сегодня») + канбан Projects.
- **Напоминания** — эфемерные пуш-комменты за 20 мин и в момент дедлайна, догон до −90 мин, само-удаление через ~5 мин.
- **Ежедневный прогон** — milestone дня, всплытие запланированных, роллновер, повторяющиеся (без дублей), дайджест, `Просрочено`/`Залежалось`, воскресное ревью.
- **Дайджесты-пирамида** — день → неделя → месяц → квартал → год со сворачиванием.
- **Быстрый ввод с телефона** — issue-форма + авто-приёмка (метки/milestone/исполнитель/дедлайн).
- **Канарейка** здоровья автоматики и **вечерний итог** дня.

### Надёжность
- Ретрай `git push` с rebase — нет потерь коммитов при гонке.
- Тесты: `bash -n` всех скриптов + тесты логики дат на каждый push.
- Всё на стандартном `GITHUB_TOKEN`, без секретов.

### Известные ограничения
- Колонки доски, Table-вид, доп. виды, поле Iteration — только через UI Projects.
- Статус с реальной колонки доски в автономных прогонах не читается (`GITHUB_TOKEN` без доступа к user-проекту) — используется метка статуса.
